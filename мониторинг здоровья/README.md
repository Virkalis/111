# GameKeys Shop — курсовой проект

Учебный интернет-магазин цифровых ключей. Визуальная структура вдохновлена распространёнными паттернами маркетплейсов цифровых товаров: каталог, фильтры, корзина, заказы, личный кабинет, отзывы, помощь и цифровая доставка.

## Страницы
- main.html — главная
- catalog.html — каталог
- cart.html — корзина
- oplata.html — оформление заказа и выдача ключа
- purchases.html — мои покупки
- profile.html — личный кабинет
- reviews.html — отзывы
- faq.html — FAQ
- delivery.html — цифровая доставка
- guarantees.html — гарантии
- contacts.html — поддержка
- info.html — инструкции
- admin.html — демонстрационная админ-панель

## Базы данных (JSON)
- database.json — склад доступных ключей
- sold-keys.json — структура проданных ключей
- products.json — каталог товаров
- users.json — пользователи
- orders.json — структура заказов
- reviews.json — отзывы
- promo-codes.json — промокоды
- support.json — обращения в поддержку
- payment-methods.json — способы оплаты
- categories.json — категории

## Важное ограничение статической версии
JSON-файлы являются исходными данными. Браузер не должен самостоятельно изменять JSON на сервере, поэтому фактические изменения демонстрационной версии (заказы, проданные ключи, отзывы, ) сохраняются в localStorage.

Для реального проекта следующий этап — перенести эти таблицы в SQLite/MySQL/PostgreSQL и добавить backend API.

## Запуск
Запускайте через VS Code + Live Server, чтобы fetch() мог читать JSON-файлы.

## Новые функции
- `auth.html` — регистрация и вход.
- `database.html` — демонстрация состояния БД склада.
- После покупки ключ физически удаляется из рабочего массива `inventoryKeys` в localStorage и добавляется в `soldKeys` с orderId/userId/email/date.
- Остаток товара в каталоге рассчитывается по рабочему складу, поэтому уменьшается после покупки.
- Отзыв можно оставить только авторизованному пользователю, который купил соответствующую игру.
`database.json` является исходным складом. В чистом браузерном режиме HTML/JavaScript не может перезаписывать JSON-файл на диске, поэтому перемещение ключей между таблицами реализовано через localStorage. Для промышленной версии эту же схему следует перенести на серверную БД/API.
